# Student Course Portal

A web-based Student Course Portal developed using HTML, CSS, JavaScript, Bootstrap, and a Node.js backend.

## 📌 About the Project

The Student Course Portal is designed to provide students with a simple and user-friendly platform to access and manage course-related information.

## 🚀 Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- Node.js
- Express.js
- MongoDB

## ✨ Features

- Student dashboard
- Course-related information
- User-friendly interface
- Responsive design
- Backend API integration
- Student data management
