# Student Course Portal

A full-stack Student Course Portal developed using HTML, CSS, JavaScript, Node.js, Express.js and MongoDB.

## Features

- Add new students
- View student details
- Update student information
- Delete student information
- Store student data in MongoDB
- REST API using Express.js

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
